# Security

## Reporting a vulnerability

Email hello@getmandateops.com with the affected version, steps to reproduce and the impact you observed. Do not open a public issue.

See https://getmandateops.com/security for what MandateOps runs on your machine, what hosted runs send to our servers, and how records are kept.

## Supported versions

Only the latest published releases of `@mandateops/cli` and `@mandateops/audit` receive security fixes.
